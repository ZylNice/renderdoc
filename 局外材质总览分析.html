2. 英雄材质（64775/64777）

完整逐行分析见姊妹篇 局外英雄材质FS分析.html，此处为摘要。
Albedo(MainTex.rgb×BaseColor, sRGB多项式解码) → LightTex 解包：x=粗糙度 / y=金属度 / z=AO+Fresnel遮罩 / w=Glow遮罩 → Matcap 环境高光（HeroMatCup，LOD=lerp(1,rough,T2.w)×6，alpha=高光ramp） → 直接光（T1.w × HeroLightIrradiance × ramp） → Fresnel 边缘光（UseFullFresnel 决定遮罩取反）→ Glow 自发光 → VS 两路加色（T3/T4，受击/Rim） → 亮度雾（luma 向 HeroFogColor 靠拢 + 保饱和修正，因子=vs_TEXCOORD7 来自 VS） → 曝光（ExposureScale+1）×ExposureColor → HDR 压半（ExposureScale.w） → Filmic tonemap（0.533/0.151/0.526/0.200/0.027）→ 输出 a=PlayerId

3. 场景材质（URP + UE 式高度雾）

完整分析见 局外雾效调试分析.html §4/§5。要点：前向 URP Lit（阴影/附加光/光照贴图全量）+ 双层指数高度雾（光学深度解析积分 → 透射率 + inscattering 合成），总开关 _MAXDeferOpaqueFog 决定雾在 PS 内合成还是走延迟 pass。

4. 特效材质详析

4.1 E1 · 双贴图滚动特效（VS 6418 / PS 6419）

代表 drawEID 2679/2681/2683（624 索引×3 连发）、3446/3448/3450（564×3 连发）——同模型三连，典型多层叠加或多位点布置
纹理_u_MainTex2（256×128，slot0）+ 128² 遮罩（slot1）
VS 常量MainTex1_ST / MainTex2_ST 双 ST、ScrollX/Y + Scroll2X/Y 双路独立滚动速度、_u_AlbedoColor/_u_Color 双色、_u_MMultiplier、_u_VisualClarity（清晰度/弱化控制）
PS 常量_u_AlphaVal（总透明度）、_u_MaskScale、_u_MultiplyAlpha、_u_UVXX、_ug_ExposureScale（与英雄共用曝光体系）
推测逻辑：color = tex1(uv·ST1 + t·Scroll1) × tex2(uv·ST2 + t·Scroll2) × Color × AlbedoColor alpha *= AlphaVal × MultiplyAlpha；VisualClarity 做远距离/低端机弱化

4.2 E2 · 遮罩+扭曲+溶解全家桶（VS 64028 / PS 64029）

代表 drawEID 3739（2484 索引）——主场景大型氛围特效
纹理4 张：_u_MaskTex（128²）+ 主图（128²）+ 256×128 + 32×128 竖条 ramp（颜色渐变查找）
VS 常量4 组 UV 滚动（Main/Mask/Dist/Diss RollUV+ST）+ _u_ZOffset（深度偏移防穿模）
PS 常量_u_CurBlendMode（shader 内混合模式选择）、_u_Dist/_u_Distortion_MainTex_Strength（UV 扭曲强度）、_u_DissFea/_u_DissInt/_u_DissolveChannel（溶解阈值/羽化/通道）、_u_Mask_Color/_u_Mask_Alpha/_u_Mask_Distortion/_u_Mask_Dissolve（遮罩图四通道分工开关）、_u_MainAlpha/_u_MultiplyAlpha

4.3 E3 · 最简单图粒子（VS 2144 / PS 2145）

VS：MainRollUV 单路滚动 + ZOffset；PS：tex × Color，alpha × MainAlpha × AlphaVal × MultiplyAlpha CurBlendMode 选择混合（加色/半透明）。代表 draw：EID 2953（1692 索引）

4.4 E4 · 溶解+Rim 幽灵特效（VS 64334 / PS 64335）

代表 drawEID 3677/3772/3866/3876（2628 索引×4 连发）
纹理主图 128² + 溶解图 256²
溶解系_u_DissInt（进度）/_u_DissFea（羽化）/_u_DissOffset/_u_DissSmooth/_u_Dissolve_Edge（边缘宽）/_u_DissColor1/_u_DissColor2（双色溶解边缘）/_u_DissolveChannel/_u_DissCoordsys/_u_Dissolve_UVChannel（坐标系与通道选择）/_u_DissIntAffectedByVertexAlpha
Rim 系_u_RimColor/_u_RimGhost/_u_RimOffset/_u_RimSmooth/_u_ReverseGhost（反向幽灵=边缘镂空反渐变）
其他_u_AsGray（去色）、_u_UseAlpha、_u_MainCoordsys、_u_Main_ClampUV；VS 带 WorldToObject + 相机位置（支持世界/视图坐标系溶解）
E4 常量多达 30 个，是局外特效里最复杂的一族——"英雄残影/灵魂现身"类表现大概率走它（ReverseGhost + 双色溶解边缘是典型特征）。

5. 特效调试配方（Shader Edit）

目的适用族改法
冻结 UV 滚动（看静帧图案）E1/E2/E3/E4Edit VS：把 _u_ScrollX/_u_ScrollY（或 *RollUV）参与的时间项乘 0；或直接把滚动后的 uv 替换为原始 uv
看主图原始采样全部PS main 末尾 SV_Target0 = texture(_u_MainTex, uv); return;
隔离遮罩通道E2输出 vec4(vec3(texture(_u_MaskTex, maskUV).x), 1.0)，x 换成 y/z/w 逐通道看
关 UV 扭曲E2把 _u_Distortion_MainTex_Strength 读取替换为常量 0.0
溶解进度手动扫动E2/E4把 _u_DissInt 读取替换为常量（0→1 逐步 Refresh，观察边缘消隐）
溶解边缘标色验证E4把 _u_DissColor1 替换为 vec4(10,0,0,1)，边缘带会发出超亮红
验证混合模式E2/E3把 _u_CurBlendMode 替换为常量逐档试；同时在 Pipeline State → Output Merger 核对 GL blend 状态（shader 内选择与实际 glBlendFunc 需一致）
排查曝光对特效的影响全部特效 PS 普遍读 _ug_ExposureScale（与英雄同体系）；把曝光乘项替换为 vec3(1.0) 看原始亮度
反向幽灵/去色开关验证E4_u_ReverseGhost/_u_AsGray 替换为 0/1 常量对比
特效 draw 普遍多连发（×3/×4 同索引）：Edit 一个 program 会同时影响所有实例。若要只观察某一个，先用它前后的 marker/事件号在 Texture Viewer 里确认渲染位置，或临时给该 draw 前后加颜色标记（把 PS 输出乘以不同纯色逐 draw 区分不可行——同 program 共享修改，需改用 Event Browser 隐藏其他 draw 的方式观察）。

6. 观测与统计建议

1) 找指定 shader 的全部 draw：MCP find_draws_by_shader "64777" → 本帧 32 个英雄 draw （EID 1560–2236 组A / 9479–10214 组B），同理可对 6419/64029/2145/64335 各特效族批量定位 2) 特效 Overdraw 排查：主 pass 尾部 6–36 索引的小 draw 极多（粒子 quad）， Texture Viewer 切到该 RT 后逐 draw 翻页看叠加层次 3) 特效贴图复用统计：Pipeline State 里纹理 ResourceId 可跨 draw 对比， 同一张 128² 被多族引用说明图集复用良好；反之可合并 4) 英雄相关进阶调试（雾/Matcap/Fresnel/Glow 隔离）见《局外英雄材质FS分析.html》§5
