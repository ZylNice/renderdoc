0. 归属判定：这不是英雄 FS

2. 逐段拆解

采样贴图(lod 0)→ 屏幕 NDC 径向暗角（可选）→ 高度淡出 alpha（可选）→ 引擎统一输出抖动

① 主采样

albedo = textureLod(T0, _62.zw, 0).rgb  // 强制 mip 0：背景是恒定距离的大平面，不需要 mip 链，省内存带宽

② 屏幕空间径向暗角（Vignette）—— 当 _m3.z > 0

ndc = _63.xy / _63.w  // 透视除法得 NDC（VS 直接透传了裁剪坐标）
p  = |ndc − _m3.xy| · _m3.z  // 相对暗角中心的偏移 × 范围缩放
r² = (p.x · _m2.w)² + p.y²  // _m2.w 做宽高比校正，得到圆形而非椭圆暗角
v  = pow(max(1 − r², 0), _m3.w)  // log2/exp2 实现的幂曲线衰减
tint = lerp(_m2.rgb, vec3(1), v)  // 中心=白(不变)，边缘=_m2 暗角色
color = albedo · tint  （仅当 _m0 ≤ 0.5 时启用，否则直通 albedo）

把视线聚焦到竞技场中央：背景边缘向 _m2.rgb 压暗/染色，是俯视竞技场的标准构图手法。暗角在屏幕空间计算（用 NDC 而非世界坐标），所以暗角始终贴合画面边缘，与相机运动无关。

③ 高度淡出 Alpha —— 当 _m0 > 0.5

alpha = (_m0 > 0.5) ? 1 − clamp(worldY / _m1, 0, 1) : 1.0

按高度线性消隐：越低越实，越高越透明。用于背景底座上沿（如围栏/远景立面）向上渐隐融入天空，避免硬切边。_m0 一物两用：同时决定「暗角是否染色」与「alpha 模式」，是该材质的变体开关。

④ 引擎统一尾巴：棋盘格输出抖动（SpecConstant 控制）

if (specID0 != 0) {
  d = {−0.0117, +0.0039, +0.0117, −0.0039}[((x&1)<<1)|(y&1)]  // 2×2 棋盘
  color += d × (specID0&3 == 1 ? 2 : specID0&3 == 2 ? 1 : 0.5，蓝噪声通道分布)
}

与英雄 FS 末尾完全相同的 epilogue——引擎在所有材质末尾统一拼接的输出抖动，抑制 8bit 输出色带。这也解释了为什么反编译两个 shader 会「长得很像」。

3. 重建的等价源码

// 背景材质 FS（语义重建）
vec3 albedo = textureLod(uTex, uv, 0.0).rgb;
vec3 color  = albedo;

if (vignetteScale > 0.0) {                 // _m3.z
    vec2 ndc = clipPos.xy / clipPos.w;
    vec2 p   = abs(ndc - vignetteCenter) * vignetteScale;   // _m3.xy/z
    float r2 = (p.x*aspect)*(p.x*aspect) + p.y*p.y;         // _m2.w
    float v  = pow(max(1.0 - r2, 0.0), vignettePow);        // _m3.w
    vec3 tint = mix(vignetteColor, vec3(1.0), v);           // _m2.rgb
    if (mode <= 0.5) color = albedo * tint;                 // _m0
}

float alpha = (mode > 0.5)                 // _m0
            ? 1.0 - clamp(worldY / fadeHeight, 0.0, 1.0)   // _m1
            : 1.0;

outColor = vec4(color + outputDither(), alpha);

5. 结论

这是场景背景材质：一张 1024² 贴图打天下，靠「屏幕空间径向暗角」聚焦视线、「高度淡出」消隐上沿，零光照零法线，成本极低。它与英雄 FS 的唯一共性是引擎统一拼接的输出抖动尾巴。帧内背景（EID 1622，约 1.47 万三角形）与英雄（EID 1674 等，约 2.8k 三角形/只）形成明显的「重角色、轻场景」资源分配策略——符合 Q 版自走棋俯视角的表现需求。
