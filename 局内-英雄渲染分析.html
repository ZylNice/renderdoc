一、英雄 draw 的识别

本截帧中，英雄棋子是 CSM 阴影图的 caster/receiver 集合中的"大网格"成员（10K 级索引）：

英雄 draw索引数VS / PS 资源角色
EID 13821033866399 / 66400标准英雄变体（主分析对象）
EID 1529837059947 / 59948SSS + 实时灯增强变体
两套 shader 均为"英雄 shader 家族"的不同变体：同一渲染框架（PBR + CSM + 环境光照）， 按英雄材质特性裁剪特性。此前「有泛光」截帧中还见过第三种 （85239，带 _u_RefEnvTex 镜面反射的变体）。
印证：英雄在棋盘上成对绘制（相同索引数连发两次 = 同卡两张棋子），且是 CSM 自阴影体系的 caster 兼 receiver。

二、顶点着色器分析 VS 66399 @ EID 1382

结构特征（SPIR-V 反编译还原）

项目内容说明
顶点输入POSITION / NORMAL / TANGENT / TEXCOORD0-2TEXCOORD2 携带逐顶点附加数据（见下）
矩阵ObjectToWorld / WorldToObject / MatrixVP标准三矩阵，无骨骼矩阵调色板
输出WS 位置 / 法线 / 切线 / UV / 雾因子世界空间 TBN 传给 PS
  • 无 GPU 蒙皮：VS 中没有任何骨骼权重采样 —— 棋子动画为 CPU 预蒙皮（每帧重写顶点 buffer）或静态姿态，符合自走棋"低频动画"的省电设计
  • 固定相机选项：_ug_EnableFixedCamera / _ug_FixedCameraPosition —— 支持锁定观察相机的特殊视角（技能特写等）
  • 高度雾逐顶点：距离雾 + 高度雾 + 域雾（_ug_YAFogDomain*）在 VS 预计算，PS 只做插值 —— 省像素成本
  • TEXCOORD2 通道： .x = 挤压缩放因子（法线按 sqrt(1-x²) 缩放）、.y = 旋转角（sin/cos 在 VS 旋转法线）、.z = ×0.6366 clamp（AO/rim 宽度类数据）、.w = 直接透传 —— 逐顶点控制轮廓/rim 形状的附加属性

3.2 着色流程（反汇编逐步还原）

① sRGB→Linear（移动端三次多项式近似，非 pow 2.2）: linear = c² × (0.3053c + 0.6822) + 0.0125c [Albedo / Emissive / SunOcclusion 均用] ② 材质: metallic×MaterialParams remap, roughness = max(r, 0.089) albedo 按金属度做 (1-metal) 漫反射 / 高光 F0 混合 ③ 法线: NormalMap ×2-1, 与 VS 传来的世界空间 TBN 合成（支持镜像 UV） ④ 主光照: _ug_LightDirectionAndAngleOffset（带角度衰减的方向光） + SunOcclusion 贴图（全局太阳遮挡） ⑤ CSM 自阴影: NormalBias 沿法线偏移 → CSM 矩阵投影 → UV 裁剪(|uv|<0.9922) → 4-tap PCF（比较采样，各 1/16 权重）→ DistanceFade 距离淡出 → shadow = 1 - strength×(1 - pcf) ← _u_ShadowStrength 逐材质可调 ⑥ 漫反射环境光: _ug_IrradianceACCoeffs（Ambient Cube，6 面 6×vec4， 按法线分量正负选择 ± 面插值）× EnvmapIntensity ⑦ 高光: GGX 预滤波 Cube（按 roughness 选 mip）× DFG split-sum × SpecularOcclusionLutBRDFCone（16×16 分格预积分高光遮挡） × _u_SelfGI（自发光 GI，×(1-shadow)·0.4 项混入） ⑧ 直射项: (albedo×0.3183 + SelfGI 贡献) × 光色 × CSM shadow + emissive × EmissiveColor + 反射项 env 高光 + AmbientCube 漫反射 ⑨ 雾: 距离雾线性混合 FogColor（VS 预计算因子） ⑩ Vignette 暗角（可选）→ 曝光（_ug_ExposureScale, 半值过渡） ⑪ 色调映射: c/(c+0.155) × 1.019 ≈ 缩放版 Reinhard → clamp 65504 → 颜色 LUT 前的 (c+0.155)/1.019 处理 ⑫ 角色底部压暗 （英雄专属）: w = smoothstep((y - Low)/(High - Low))^Power ← _ug_BottomDarkenHeight{Low,High,Power} color = mix(color, color × BottomDarkenColor, w) （_ug_IsCharacterBottomDarken 开关，仅角色开启 —— 强化棋子与地面的接触感） ⑬ MaskScale 输出遮罩 + 最终 clamp

六、移动端优化观察

  • sRGB 解码用三次多项式近似（c²(0.3053c+0.6822)+0.0125c）代替 pow 2.2 —— 每纹理采样省 3 次通用函数调用
  • 环境漫反射用 Ambient Cube（6×vec4）而非 SH —— 常量更少、单次分量选择代替多项式求值
  • 高光遮挡走 16×16 预积分 LUT（SpecularOcclusionLutBRDFCone）而非解析式 —— 用一次采样替代 Cone/AO 推导
  • 雾在 VS 计算，PS 仅插值 —— 逐顶点足够（棋子顶点密度高）
  • 无 GPU 蒙皮 —— 动画 CPU 化或静态，降低 shader ALU
  • 色调映射为缩放 Reinhard 近似（c/(c+0.155)×1.019），无 ACES 级开销
  • 底部压暗（BottomDarken）替代复杂接触阴影 —— 用世界 Y 高度的 smoothstep 幂曲线混合暗色，强化"站在地上"的感觉
  • 变体按需裁剪：SSS/实时灯/镜面反射作为独立 shader 变体存在，普通英雄不付这些成本
