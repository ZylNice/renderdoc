3.3 逻辑流程

世界变换 worldM·pos→ viewProj·worldPos 得裁剪坐标→ 法线/切线分别用对应矩阵变换并归一化→ 双雾效因子计算（距离雾 + 到雾中心径向雾，clamp 后 ×0.1 写入 w）→ Push Constant 后处理（UnpackSnorm4x8 做视口/翻转校正，ANGLE 特性）
没有 GPU 蒙皮：常量中无骨骼矩阵数组，顶点仅经单一世界矩阵变换。万象棋棋子（Q 版英雄）的动画应为烘焙顶点动画或静态 pose，每帧由 CPU 侧更新顶点缓冲。

4. 像素着色器分析（1587007）—— 卡通 PBR 混合材质

这是该材质的核心：在标准 GGX PBR 骨架上叠加卡通高光 Ramp（Matcap 阵列）、SH9 环境光、边缘光、双雾效与屏幕抖动透明，最后经自定义 Filmic ToneMapping 输出。

4.1 整体数据流

Albedo(sRGB解码)×染色→ 金属度/粗糙度（遮罩图×系数）→ 法线贴图 TBN → 世界法线→ Bayer 抖动镂空 (Kill)→ 直接光 GGX+ 卡通高光 Ramp+ SH9 环境漫反射+ BRDF LUT 环境高光→ 距离雾/高度雾→ 边缘光→ Filmic Tonemap→ 输出抖动(SpecConst)

4.2 分步拆解

① 反照率与 sRGB 解码

uv = UV0 · ST.xy + ST.zw  // ST = child20
albedo = T0(uv)  // 256×256
albedo = albedo·(albedo·(albedo·0.3053 + 0.6822) + 0.0125)  // 快速 sRGB→Linear 近似（与精确曲线误差 <0.5%）
albedo *= child21.rgb  // 材质染色

② 金属度 / 粗糙度 / 不透明度（遮罩图 T1）

metallic  = T1.x · child8
roughness = max(T1.y · child7, 0.089)  // GGX 下限防奇异
alpha     = T0.w · child21.w

粗糙度平方 a = roughness² 缓存供 GGX 使用；child25 参与漫反射衰减 (1 - T1.y·child25) 形式的重映射（类能量守恒的 diffuse 缩放）。

③ 法线贴图与 TBN

n_t = T3(uv)·2 − 1; n_t = normalize(n_t)
N = normalize(vNormal);  T' = normalize(vTangent − N·dot(N,vTangent))  // Gram-Schmidt 正交化
B = cross(N, T') · sign(child24.w) · vTangent.w  // 双面手性校正
Nw = T'·n_t.x + B·n_t.y + N·n_t.z

④ Bayer 4×4 屏幕门抖动透明（Dithered Transparency）

sUV = (clipPos.xy / clipPos.w) · child26.xy · 0.25
bayer = Bayer4x4[floor(fract(|sUV|)·4)]  // 由 4 行单位矩阵与常数 {0.0588, 0.7647, …} 点积重建
if (bayer − child9 < 0) discard;

用 4×4 有序抖动 + Kill() 实现英雄淡入淡出/半透明，避免真实混合排序，是王者系角色的典型做法。

⑤ 直接光 GGX（主光源方向 child12，颜色 child13，强度 child5）

H = normalize(V + L);  NdotH、NdotL、NdotV、VdotH 均 saturate
D  = a² / (π·(NdotH²·(a²−1)+1)²)  // 代码中 0.3183 = 1/π
Vis = 简化 Smith（(2−a)·NdotV+NdotL 形式的合一近似）
F  = F0 + (1−F0)·(1−VdotH)⁴·…  // Schlick 变体
F0 = lerp(0.04, albedo−0.04 系, metallic)  // 绝缘体 0.04 与金属 albedo 间插值
spec = D·Vis·F  +  diffuse = albedo/π

⑥ 卡通高光 Ramp / Matcap 阵列（T4，256×128，本材质的灵魂）

R = reflect(−V, Nw);  R.xz 绕 Y 轴旋转 child4·0.0175 rad（度→弧度，可调高光朝向）
φ = atan2 多项式近似(R)  // 系数 0.0208/−0.0851/0.1801/−0.3303/0.9999
θ = acos 多项式近似(R.y)  // 系数 −0.0187/0.0743/−0.2121/1.5707
u = φ·(1/π)·0.5+0.5，v = θ·(1/π)… → 球面 UV
row = roughness·5；采样 floor(row) 与 ceil(row) 两条带（条带偏移表 {0.5,0.5,0/0.5}、{0.25,0.25,0.75…} 共 5 段），按小数部分 lerp
specRamp = ramp²（平方提亮）· child17.rgb（高光色）· 遮罩

等效于一张按粗糙度分 5 档预烘焙的 Matcap 图集：用反射向量球面坐标取卡通化高光形状，再随粗糙度在两档间插值——用 1 次纹理采样 + 1 次 lerp 替代昂贵的环境卷积，获得风格化但粗糙度可控的高光。

⑦ SH9 球谐环境光（间接漫反射）

// 标准 Ramamoorthi SH 基常数逐一出现：0.4290(c1) / 0.7431(c3) / 0.8862(c4) / 0.2477(c5) / 0.8581 / 1.0233
sh = c4·child28 − c5·child34.y + c3·z²·child34 − c5·(x²−y²) 项…（7 个系数向量 child28–34）
indirect = sh · child15 · child14 · albedo

与 Unity ShadeSH9 结构一致，7 个 float4 系数由引擎逐帧/逐区域烘焙传入。

⑧ 环境高光（Split-Sum + BRDF LUT，T6 32×32）

lut = T6(NdotV, roughness)  // 预积分 GGX 环境 BRDF
envSpec = F0·lut.x + lut.y  →  与 specRamp 合并后乘环境色

⑨ 雾效（双重）

距离雾：color = lerp(color, child19.rgb, vFog)  // vFog 由 VS 写入，相机距离驱动
高度雾：h = saturate((worldY − child3)·child2)；color = lerp(color, child11.rgb, h)

⑩ 边缘光（Rim）

rim = lerp((1−NdotV)⁴, (1−NdotV)⁴·child0, …) · child10.rgb
color += rim;  color = clamp(color, 0, 1)

⑪ HDR 处理与自定义 Filmic ToneMapping

if (child18.w > 0)  // HDR 标记：>1 时减半亮度，否则直通
color = color·(0.533·color + 0.151) / (color·(0.526·color + 0.200) + 0.027)  // 有理函数 Filmic 曲线

5. 结论

维度结论
材质风格卡通化 PBR 混合：GGX 直接光 + Matcap 高光图集（5 档粗糙度）+ SH9 环境 + BRDF LUT，兼顾风格化与材质区分度
顶点阶段无 GPU 蒙皮，单世界矩阵；VS 提前计算雾因子与屏幕抖动坐标，减轻 PS 负担
透明方案Bayer 屏幕门抖动 + discard，规避半透明排序
性能特征PS 共 7 次纹理采样（其中 2 张 4×4、1 张 32×32 极廉价）；atan/acos 全用多项式近似；无分支循环，适合移动端 tile GPU
兼容性GLSL450 经 ANGLE 转 SPIR-V，Push Constant 做坐标系校正，Specialization Constant 控制输出抖动开关
变体不同英雄有不同精简变体（如 EID 1970：4 贴图版本，去掉法线/Ramp/LUT 中的部分通道）
