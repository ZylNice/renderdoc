2.2 完整执行链

Albedo(MainTex.rgb × BaseColor, sRGB 三次多项式解码 c·(c·0.305306+0.682171)+0.012523) → LightTex 解包：x=粗糙度 / y=金属度 / z=AO+Fresnel 遮罩 / w=Glow 遮罩 → 金属度增益：albedo ×= lerp(非金属强度, 金属强度, m)；albedo += m·albedo·MetallicAlbedoMultiplier → Matcap 环境高光：textureLod(HeroMatCup, T2.xy·0.5+0.5, rough·6)，rgb²转线性 F0 = T2.z·clamp(0.532−rough) + (1−m)·0.04；specRamp = m·albedo + F0 env = matcap·HeroEvnIntensity·specRamp·T1.xyz·反射强度lerp·AO·亮部反射提亮 → 直接光：direct = (T1.w × HeroLightIrradiance) × (matcap.a × specRamp × T2.w) → Fresnel 边缘光：mask = UseFullFresnel ? 1−LightTex.z : LightTex.z；+= mask·T3.w·FresnelColor → Glow 自发光：+= LightTex.w · GlowColor² · GlowIntension → VS 两路加色：+= clamp(T4.rgb)·MulColor（受击/技能染色）+ clamp(T3.rgb)（Rim/Hurt） → 亮度雾：fogged = color + (luma(HeroFogColor) − luma(color)) · vs_TEXCOORD7 + 保饱和修正（min<0 回拉 / max>1 压缩），雾因子由 VS 用 HeroFogParam/HeroFogIntensity 预算 → 曝光：×(ExposureScale.rgb+1)×ExposureColor；ExposureScale.w>0 走 HDR 分支（w>1 不压，否则 ×0.5） → Filmic tonemap：c·(0.533c+0.151) / (c·(0.526c+0.200)+0.027) → 输出：alpha 恒为 _u_PlayerId（供描边/选中 pass 像素级识别，非透明度）
