0. 重要：当前 shader 处于"纯白"改动状态

EID 1745 的 PS（64777）反编译末尾存在一行 *_uSV_Target0 = {1.0000, 1.0000, 1.0000, 1.0000}; —— 即上一轮的"输出纯白"修改仍在生效，它覆盖了包括雾效在内的全部原始计算。开始调试雾效前，请先在 Shader Viewer → Edit 中删掉这一行（GLSL 源码视图里是 SV_Target0 = vec4(1.0);），恢复原始逻辑。

1. 本截帧的两套雾系统

雾系统所属 shader雾因子来源PS 中的形态
A. 英雄亮度雾英雄 FS 64777（EID 1745）VS 预算 → varying vs_TEXCOORD7（float）亮度插值：把像素亮度向雾色亮度拉近，并做保饱和度修正
B. 场景 UE 式高度雾场景/背景 FS（即 D:\新建 文本文档.txt，5949 行）PS 内逐像素解析积分（世界坐标 vs_TEXCOORD1 + 相机位置）双层指数高度雾 + 方向性日光 inscattering + Inscattering Cubemap，MAXFOGCBuffer（binding 2）传参

2. 英雄亮度雾（FS 64777）逻辑精解

2.1 雾效代码段（SPIR-V → GLSL 还原）

// vs_TEXCOORD7 = VS 传入的雾因子（0=无雾，1=全雾） float fogLuma = dot(_ug_HeroFogColor.rgb, vec3(0.3, 0.59, 0.11)); float pixLuma = dot(color, vec3(0.3, 0.59, 0.11)); float lumaDiff = fogLuma - pixLuma; color = color + vec3(lumaDiff) * vs_TEXCOORD7; // ★ 核心：只改亮度，不改色相 // 保饱和度修正（亮度推移后越界则重算） float minC = min(min(color.r, color.g), color.b); float maxC = max(max(color.r, color.g), color.b); if (minC < 0.0) color = luma + (color - luma) * luma / (luma - minC); // 负通道回拉 if (maxC > 1.0) color = luma + (color - luma) * (1.0 - luma) / (maxC - luma); // 超亮压缩

2.2 雾之后的固定流程

亮度雾混合→ 保饱和修正→ ×(_ug_ExposureScale.rgb+1)×_u_ExposureColor→ HDR 压半(_ug_ExposureScale.w)→ Filmic tonemap→ 输出(w=_u_PlayerId)
雾在 tonemap 之前。所以把雾因子直接覆写到 SV_Target0 时务必 return 跳过后续，否则你看到的是 tonemap 后的因子，数值失真。

2.3 雾因子的来源（VS 64775，$Globals）

常量含义
_ug_HeroFogColor (vec4)英雄雾颜色（PS 只取 rgb 算亮度）
_ug_HeroFogIntensity (float)雾强度
_ug_HeroFogParam (vec4)雾距离参数（起点/斜率等，VS 内参与因子计算）
PS 改不了雾的"远近/浓度曲线"——因子在 VS 里由 _ug_HeroFogParam/_ug_HeroFogIntensity 算出后经 vs_TEXCOORD7 插值传入。要调曲线形态请 Edit VS（64775）。

3. 英雄雾：Shader Edit 调试配方

操作路径：Event Browser 选 EID 1745 → Pipeline State → FS 阶段 → Edit → 改完 Refresh 重放整帧。

目的改法（GLSL 反编译源码）
恢复正常（撤销纯白）删掉末尾 SV_Target0 = vec4(1.0, 1.0, 1.0, 1.0); 一行
可视化雾因子分布main 开头插入：SV_Target0 = vec4(vec3(vs_TEXCOORD7), 1.0); return;（黑=无雾，白=全雾）
可视化雾色亮度差在 lumaDiff 算完后插入：SV_Target0 = vec4(vec3(lumaDiff) * 0.5 + 0.5, 1.0); return;（0.5 灰=无差异，偏亮=雾更亮）
关闭英雄雾把 color + vec3(lumaDiff) * vs_TEXCOORD7 对应那行（反编译为 u_xlat16_2 = ... 的累加行）改为直接 u_xlat16_2.xyz = u_xlat16_0.xyz;（即不加 diff 项）
雾拉满看极限效果把该行里的 vs_TEXCOORD7 替换为常量 1.0
雾色标红看作用范围把 _ug_HeroFogColor 的读取替换为 vec4(10.0, 0.0, 0.0, 1.0)（超亮红，雾区一目了然）
调雾的远近/浓度曲线Edit VS 64775：找到写 vs_TEXCOORD7 的赋值，乘系数或改 _ug_HeroFogParam 的参与方式

4. 场景 UE 式高度雾（背景 FS）逻辑精解

4.1 两段式结构

① 光学深度积分（567–667 行）→ …（中间是光照/GGX/阴影，与雾无关）…→ ② 雾应用（5873–5926 行）→ 曝光/输出（5936–5947 行）
// ① 因子段（567–667）：相机→像素射线做解析积分 dist = length(worldPos - camPos); // u_xlat0.x // 提前退出：dist < _StartDistance 或 _FogMaxOpacity<=0 或 dist > _FogCutoffDistance // → 透射率 u_xlat10.x=1，无雾 // 第一层：_FogDensity/_FogHeight/_FogHeightFalloff → 光学深度 u_xlat111 // 第二层：_SecondFogDensity/... → 光学深度 u_xlat310（叠加） optDepth = layer1 + layer2; // u_xlat310（643 行合并） transmittance = max(1 - _FogMaxOpacity, exp2(-optDepth)); // u_xlat10.x firstLayerWeight = u_xlat311; // 第一层占雾色权重 secondLayerWeight = u_xlat304; // 第二层权重（含方向性衰减） // ② 应用段（5873–5926）：仅当 _MAXDeferOpaqueFog <= 0.5 走此分支 fogColor = (_FogInscatteringColor * firstLayerWeight + _SecondFogInscatteringColor * secondLayerWeight) * InscatteringCubemap(可选) * (1 - transmittance); fogColor += 方向性日光散射(pow(NdotL_sun, _DirectionalInscatteringExponent)) + 天空环境贡献(_AtmoSkyIrradiance * _HeightFogContribution); color = litColor * transmittance + fogColor; // ★ 5926 行：最终合成

4.2 关键常量（MAXFOGCBuffer，binding 2）

常量含义常量含义
_FogInscatteringColor第一层雾色_SecondFogInscatteringColor第二层雾色
_FogDensity第一层浓度_SecondFogDensity第二层浓度
_FogHeight / _FogHeightFalloff第一层基准高度/衰减_SecondFogHeight(Falloff)第二层
_FogMaxOpacity最大不透明度（钳透射率下限）_FogCutoffDistance截断距离（>0 且 dist 超程则无雾）
_StartDistance / _StartDistanceSoftWidth雾起点距离 / 软过渡宽度_FogOrigin雾原点（w 为混合权重）
_MAXDeferOpaqueFog总开关：≤0.5 时 PS 内应用雾；>0.5 走延迟/合成 pass_HeightFogContribution高度雾对大气项的贡献系数

6. 不改 shader 的观测手段

1) Event Browser 选 EID 1745 → Texture Viewer 右键目标像素 → Debug Pixel，逐指令看 vs_TEXCOORD7（英雄雾因子）/ u_xlat10.x（场景透射率）等中间值 2) Pipeline State → VS → $Globals：查看 _ug_HeroFogColor / _ug_HeroFogIntensity / _ug_HeroFogParam 运行时值 3) Pipeline State → FS → Uniform Buffers → MAXFOGCBuffer(binding 2)：整套高度雾参数当前值 4) 对比法：同一像素分别 Debug 英雄 draw 与背景 draw，看两套雾因子是否匹配（接缝问题排查）
