Shader：PS ResourceId::64777 / VS ResourceId::64775 ｜ 代表 draw：EID 1652 glDrawElements（8988 索引）｜ RT：ResourceId::69655 ｜ 来源：RenderDoc 反编译 GLSL 450 ｜ 截帧：MAX-局外-真机截帧.rdc（OpenGL ES）

0. 归属与关联

本 GLSL 即局外英雄 FS（64777）：3 张 256² 纹理 + $Globals 22 个常量 + 6 路 varying。EID 1652（8988 索引）与 EID 1745（666 索引）共用同一 shader program——Shader Edit 一旦 Apply，所有使用该 program 的英雄 draw 同时生效。
若此前做过"输出纯白"的实验修改（末尾 _uSV_Target0 = vec4(1.0);），请先删除该行再开始材质/雾效调试。

1. 接口映射

1.1 顶点输入（VS 64775 传入的 varying）

变量分量含义
_uvs_TEXCOORD0xy主 UV（_u_MainTex / _u_LightTex 共用）
_uvs_TEXCOORD1xyz环境项调制（乘 Matcap 环境结果；顶点烘焙 AO/环境色）
_uvs_TEXCOORD1w直接光强度系数（×_ug_HeroLightIrradiance 得主光辐照）
_uvs_TEXCOORD2xyMatcap UV 源（视角空间法线 xy；×0.5+0.5 映射到 [0,1]）
_uvs_TEXCOORD2z高光基数（参与 F0 项：z × clamp(0.532−lod) + (1−metal)×0.04）
_uvs_TEXCOORD2w高光衰减/AO：lerp 粗糙度（1→rough）、乘 spec ramp、乘环境项
_uvs_TEXCOORD3xyzVS 加色①（clamp 0..1 后直加；对应 VS 的 RimColor/HurtColor 通路）
_uvs_TEXCOORD3wFresnel 强度系数（乘在 fresnel 权重上）
_uvs_TEXCOORD4xyzVS 加色②（clamp 0..1，×_u_MulColor 后直加）
_uvs_TEXCOORD7x英雄雾因子（VS 由 _ug_HeroFogParam/_ug_HeroFogIntensity 预算，0=无雾 1=全雾）

1.2 纹理

变量ResourceId尺寸/Mip通道用途
_u_MainTex67240256² / 9 mipsrgb = Albedo（×_u_BaseColor 染色；走 sRGB 多项式解码）；a 未使用
_u_LightTex67527256² / 1 mipx = 粗糙度遮罩　y = 金属度遮罩　z = AO + Fresnel 遮罩（一图两用）　w = 自发光(Glow)遮罩
_u_HeroMatCup67526256² / 1 mipMatcap 高光图集（rgb 采样后平方≈转线性；a = 高光 ramp 遮罩）；LOD = lerp(1, rough, T2.w)×6 手动指定

2. 执行流程总览

① Albedo×BaseColor→ ② LightTex 解包(粗糙/金属/AO/Glow)→ ③ 金属度 Albedo 增益+sRGB解码→ ④ Matcap 环境高光→ ⑤ 直接光(HeroLightIrradiance)→ ⑥ Fresnel 边缘光→ ⑦ Glow 自发光→ ⑧ VS 加色(T3/T4)→ ⑨ 亮度雾→ ⑩ 保饱和修正→ ⑪ 曝光/HDR压半→ ⑫ Filmic Tonemap→ 输出(a=PlayerId)

3. 关键代码段精解

① Albedo 与金属度增益

albedo = texture(_u_MainTex, uv).rgb * _u_BaseColor.rgb; albedoLuma = dot(albedo0, vec3(0.22, 0.707, 0.071)); // 存下备用（反射提亮） metalMask = clamp(LightTex.y * MetalRemap.y + MetalRemap.x, 0, 1); albedo *= lerp(_ug_HeroNonMetalAlbedoIntensity, _ug_HeroMetalAlbedoIntensity, metalMask); albedo += metalMask * albedo * _u_MetallicAlbedoMultiplier; // 金属额外提亮 // sRGB 快速解码（三次多项式）：c*(c*0.305306 + 0.682171) + 0.012523 albedo *= albedo * (albedo * 0.305306 + 0.682171) + 0.012523;

② 粗糙度与 Matcap LOD

rough = clamp(LightTex.x * RoughRemap.y + RoughRemap.x, 0, 1); rough = lerp(1.0, rough, T2.w); // T2.w=0 时强制最粗糙（关掉高光条带） matcupLOD = rough * 6.0; // 图集 6 档粗糙度 matcap = textureLod(_u_HeroMatCup, T2.xy*0.5+0.5, matcupLOD); matcap.rgb = matcap.rgb²; // 平方近似 gamma→线性

③ 环境高光（Matcap × F0 ramp）

F0base = lerp(0.04, 0, metalMask); // 非金属 0.04 F0 = T2.z * clamp(0.532 - rough, 0, 1) + F0base; // T2.z=高光基数 specRamp = metalMask * albedo + F0; // 金属吃 albedo 色 env = matcap.rgb * _ug_HeroEvnIntensity * specRamp * T1.xyz; // T1.xyz=环境调制 env *= lerp(_ug_HeroNonMetalRefIntensity, _ug_HeroMetalRefIntensity, metalMask); env *= (1 + _u_AOIntensity * (LightTex.z - 1)); // AO 压暗 env *= (albedoLuma^AlbedoLuminancePower × ReflectionBrightenIntensity + 1); // 亮部反射更亮

④ 直接光（高光 ramp 驱动）

direct = (T1.w × _ug_HeroLightIrradiance) // 主光辐照（VS 算好 NdotL/衰减） × (matcap.a × specRamp × T2.w); // matcup alpha = 高光形状 ramp color = albedo通路×specRamp + env + direct×反射强度lerp;

⑤ Fresnel 边缘光

fmask = _u_UseFullFresnel ? (1 - LightTex.z) : LightTex.z; // 复用 z 通道 fresnel = fmask × T3.w; // T3.w = VS 算的 NdotV 类权重 color += fresnel × _u_FresnelColor.rgb;

⑥ Glow 自发光 与 VS 加色

glow = LightTex.w × _u_GlowColor² × _u_GlowIntension; // 颜色平方=增强饱和 color = color×曝光预乘 + glow; color += clamp(T4.xyz, 0, 1) × _u_MulColor; // VS 加色②（受击/技能染色） color += clamp(T3.xyz, 0, 1); // VS 加色①（Rim/Hurt）

⑦ 亮度雾（保饱和，调试点见 §5）

fogLuma = dot(_ug_HeroFogColor.rgb, vec3(0.3, 0.59, 0.11)); pixLuma = dot(color, vec3(0.3, 0.59, 0.11)); diff = fogLuma - pixLuma; fogged = color + diff × _uvs_TEXCOORD7; // ★ 只推亮度，不动色相 newLuma = pixLuma + diff × _uvs_TEXCOORD7; // 保饱和修正：通道越界则沿亮度方向回拉/压缩 if (min(fogged) < 0) fogged = newLuma + (fogged - newLuma) × newLuma / (newLuma - minC); if (max(fogged) > 1) fogged = newLuma + (fogged - newLuma) × (1 - newLuma) / (maxC - newLuma);

⑧ 曝光 / HDR / Tonemap / 输出

color *= (_ug_ExposureScale.rgb + 1) × _u_ExposureColor; // 两级染色 if (_ug_ExposureScale.w > 0) { // HDR 模式 hdrColor = _ug_ExposureScale.w > 1 ? color : color×0.5; hdrColor.a = _u_PlayerId; // HDR 分支输出 } ldr = c×(0.533c+0.151) / (c×(0.526c+0.200)+0.027); // Filmic 有理曲线 ldr.a = _u_PlayerId; out = HDR模式 ? hdrColor : ldr; // alpha 恒为 PlayerId
alpha 通道写 _u_PlayerId 而非透明度——供后续 pass（描边/选中/阵营区分）做像素级识别，调试时别把 RT 当普通 RGBA 颜色读 a 通道。

5.1 雾效调试

目的改法
可视化雾因子分布main 开头插 _uSV_Target0 = vec4(vec3(_uvs_TEXCOORD7), 1.0); return;（黑=无雾，白=全雾）
关闭雾雾混合行 (_uu_xlat16_2.xyz = ((_uu_xlat16_1.xxx * vec3(_uvs_TEXCOORD7)) + _uu_xlat16_0.xyz)); 改为 (_uu_xlat16_2.xyz = _uu_xlat16_0.xyz);（后续保饱和修正自动退化为近似原色）
雾拉满看极限同一行里 _uvs_TEXCOORD7 替换为 1.0
雾色标红看范围fogLuma 那行 dot(_ug_HeroFogColor.xyz, ...) 改为 dot(vec3(10.0, 0.0, 0.0), ...)
验证保饱和修正是否触发在两个 bool(_uu_xlatb0) ? ... 选择行分别输出纯红/纯蓝：_uSV_Target0 = vec4(_uu_xlatb0 ? vec3(1,0,0) : vec3(0,0,1), 1.0); return;
调雾远近/浓度曲线PS 改不了——因子在 VS 64775 内由 _ug_HeroFogParam / _ug_HeroFogIntensity 算出，Edit VS 中写 vs_TEXCOORD7 的语句乘系数即可

5.2 材质分项隔离

目的改法（插入位置 = 对应代码段算完之后）
看原始 Albedo① 段 sRGB 解码后：_uSV_Target0 = vec4(_uu_xlat16_10.xyz, 1.0); return;
看粗糙度/金属度② 段 remap clamp 后：_uSV_Target0 = vec4(_uu_xlat16_21.x, _uu_xlat16_21.y, 0.0, 1.0); return;（R=粗糙 G=金属）
看 AO/Fresnel 遮罩LightTex 采样后：_uSV_Target0 = vec4(vec3(_uu_xlat16_0.z), 1.0); return;
看 Glow 遮罩同上位置：_uSV_Target0 = vec4(vec3(_uu_xlat16_0.w), 1.0); return;
看 Matcap 采样textureLod 后：_uSV_Target0 = vec4(_uu_xlat16_5.xyz, 1.0); return;
隔离环境高光合成行改为只保留 env 项（_uu_xlat16_3.xyw 通路），其余加项清零
隔离直接光在 _uu_xlat16_1.xyz = ((_uu_xlat16_2.xyz * vec3(_uu_xlat16_29)) + ... 后插 _uSV_Target0 = vec4(_uu_xlat16_2.xyz * vec3(_uu_xlat16_29), 1.0); return;
隔离 Fresnel 贡献Fresnel 累加行后：_uSV_Target0 = vec4(_uu_xlat16_21.xxx * _u_FresnelColor.xyz, 1.0); return;
隔离 Glow 贡献⑥ 段：_uSV_Target0 = vec4(_uu_xlat16_4.xzw, 1.0); return;
隔离 VS 加色T3/T4 累加后对比注释掉两行直加（排查受击染色/Rim 异常）
跳过 Tonemap 看线性 HDR末尾输出改为 _uSV_Target0 = vec4(_uu_xlat16_0.xyz * 0.1, 1.0);（×0.1 防过曝）
排查 HDR 分支强制 _uu_xlatb8 = true/false 对比两条输出路径
所有 return; 式可视化都会跳过后续计算（雾/曝光/tonemap），看到的是原始中间值——这正是目的；但要记得 alpha 恒为 1，不再带 PlayerId，后续依赖 alpha 的 pass 表现会失真，属预期现象。

6. 不改 shader 的观测手段

1) Texture Viewer 右键英雄像素 → Debug Pixel：逐指令看 _uvs_TEXCOORD7（雾因子）、 _uu_xlat16_21（粗糙/金属）、_uu_xlat16_0.z/w（AO/Glow 遮罩）等运行时值 2) Pipeline State → FS → $Globals：22 个常量当前值整表查看 （重点：_ug_HeroFogColor / _ug_ExposureScale.w / _u_UseFullFresnel） 3) Pipeline State → VS 64775 → $Globals：_ug_HeroFogIntensity / _ug_HeroFogParam（雾曲线源头） 4) 三张纹理右键可单独查看通道（LightTex 建议逐通道看 x/y/z/w 四张遮罩图） 5) 同 program 对照：EID 1652（8988 索引）与 EID 1745（666 索引）同 shader 不同网格， 改一次 FS 两者同时变化，可用于验证修改对不同体型英雄的一致性
