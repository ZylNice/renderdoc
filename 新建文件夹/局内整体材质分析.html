2. 英雄材质（75310/75311）摘要

与局外英雄 shader（64775/64777）常量表逐项一致（VS 23 项 / PS 22 项），同一架构： Albedo(MainTex.rgb × BaseColor, sRGB 多项式解码) → LightTex 解包：x=粗糙度 / y=金属度 / z=AO+Fresnel 遮罩 / w=Glow 遮罩 → Matcap 环境高光（HeroMatCup，LOD=粗糙度×6，a=高光 ramp） → 直接光（T1.w × HeroLightIrradiance × ramp）→ Fresnel（UseFullFresnel 取反）→ Glow → VS 两路加色（T3 Rim/Hurt、T4 ×MulColor 受击染色） → 亮度雾（luma 向 HeroFogColor 靠拢 + 保饱和修正，因子 vs_TEXCOORD7 来自 VS HeroFogParam） → 曝光(ExposureScale+1)×ExposureColor → HDR 压半 → Filmic tonemap(0.533/0.151/0.526/0.2/0.027) → 输出 alpha = _u_PlayerId（供描边 pass 识别）
本帧英雄纹理实例：MainTex 77150（256²/9mips）+ LightTex 379746 + MatCup 379745。VS $Globals 含 _u_RimColor/_u_HurtColor/_u_RimLightDirWS/_ug_HeroEnableFixedCamera/_ug_HeroFixedCameraPosition（局内战镜固定相机支持）。
