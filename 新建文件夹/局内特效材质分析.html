4.2 已验证的像素逻辑（SPIR-V 反编译）

t = (_u_ChangeValue >= LightOnTex.a) ? 1 : 0; // IsSmoothChange 时用平滑值 color = lerp(MainTex.rgb, LightOnTex.rgb, t); // 熄灭格 → 点亮格 if (_u_GameState == 1) color.rgb = lerp(color.rgb, tex(LightenStateTex).rgb, _u_StateChangeValue); color *= _u_Color; if (_u_IsAlphaTest && color.a×_u_MainAlpha < _u_CutOffValue) discard; // 暗角（前向 pass 内逐像素，非后处理）： if (_u_Vignette_Params2.z > 0) { sUV = gl_FragCoord.xy / _ug_ScreenParams.xy; // 屏幕 UV（ProjectionParams.x 控 Y 翻转） d = abs(sUV - Params2.xy) × Params2.z; d.x *= Params1.w; v = pow(max(1 − dot(d,d), 0), Params2.w); vig = lerp(Params1.rgb, vec3(1), v); // 中心白、边缘 Params1.rgb out.rgb = (_ug_EnableBlurReflection ≤ 0.5) ? color.rgb × vig : color.rgb; // 反射门控 }
暗角只压棋盘地面、不压英雄/特效（刻意聚焦棋盘中心）；开模糊反射时跳过暗角避免压两次。因此"关暗角"应把 vig 替换 vec3(1.0)，而不是动反射开关。

5. 泛光（Bloom）链 · 57736/57737

5.1 结构

17 个全屏三角形 draw（EID 7063–7388，各 3 索引），分布于 Colour Pass #3–#18： 首 pass（EID 7063）阈值提取： 输入 _u_BloomSrcTex = 2132×1198 全分辨率场景 RT（ResourceId 80804） 常量：_u_Threshold（亮度阈值）/ _u_Params / _u_PostExposure（后曝光） / _u_ExposureParams / _ug_ExposureScale / g_ColorMatrix（调色矩阵） 中间：逐级降采样模糊 → 逐级上采样累加（每层 1 pass = 3 事件：SetRT+Draw+恢复） 末 pass：合成回主 RT（泛光叠加到场景）
泛光链路结论：阈值提取 RT 中仅剩超阈值亮斑（技能/高光/英雄 Glow 为主要亮斑源），逐级扩散后合成回主 RT；特效高亮与英雄 HDR 输出是泛光强度的直接上游。
