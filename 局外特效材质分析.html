1. E1 · 双贴图滚动特效（VS 6418 / PS 6419）

1.1 资源与常量

纹理slot0 _u_MainTex2 256×128；slot1 遮罩 128²（均 R8G8B8A8）
VS $Globals（13 项）_u_MainTex1_ST/_u_MainTex2_ST 双 ST；_u_ScrollX/_u_ScrollY + _u_Scroll2X/_u_Scroll2Y 双路独立滚动速度；_u_AlbedoColor/_u_Color 双色；_u_MMultiplier；_u_VisualClarity（清晰度/弱化）；_u_Time + MVP/OW 矩阵
PS $Globals（6 项）_u_AlphaVal（总透明度）、_u_MaskScale、_u_MultiplyAlpha、_u_UVXX、_u_VisualClarity、_ug_ExposureScale

1.2 推测逻辑

uv1 = uv·ST1 + t·(ScrollX, ScrollY); uv2 = uv·ST2 + t·(Scroll2X, Scroll2Y) color = tex1(uv1) × tex2(uv2) × _u_Color × _u_AlbedoColor × _u_MMultiplier alpha *= _u_AlphaVal × _u_MultiplyAlpha × Mask(遮罩图，_u_MaskScale) 最后 × _ug_ExposureScale 曝光；VisualClarity 做远距离/低端机弱化

2. E2 · 遮罩+扭曲+溶解全家桶（VS 64028 / PS 64029）

2.1 资源与常量

纹理4 张：slot0 _u_MaskTex 128²；slot1 主图 128²；slot2 256×128（扭曲/噪声）；slot3 32×128 竖条 ramp（颜色渐变查找表）
VS $Globals（14 项）4 组 UV 滚动+ST：Main / Mask / Dist（扭曲）/ Diss（溶解）各一套 RollUV + ST；_u_ZOffset（深度偏移防穿模）；_u_ProjectionParams；MVP/OW/W2O 矩阵
PS $Globals（16 项）_u_Color；_u_CurBlendMode（shader 内混合模式选择）；_u_Dist / _u_Distortion_MainTex_Strength / _u_Distortion_DissolveTex（UV 扭曲）；_u_DissFea/_u_DissInt/_u_DissolveChannel/_u_DissIntAffectedByVertexAlpha（溶解阈值/羽化/通道/顶点alpha联动）；_u_Mask_Color/_u_Mask_Alpha/_u_Mask_Distortion/_u_Mask_Dissolve/_u_MaskChannel（遮罩图分工开关）；_u_MainAlpha/_u_MultiplyAlpha

2.2 推测逻辑

distUV = uv + 扭曲图采样 × _u_Distortion_MainTex_Strength // 主图扭曲 main = tex_main(distUV 滚动后) × _u_Color × ramp(32×128 查表) mask = tex_MaskTex(uv 滚动后)，按 Mask_Color/Alpha/Distortion/Dissolve 开关 把 mask 的某通道（_u_MaskChannel）分别用于：调色 / alpha / 扭曲量 / 溶解阈值 dissolve = step/smoothstep(溶解图通道, _u_DissInt ± _u_DissFea 羽化) alpha = main.a × mask.a × dissolve × _u_MainAlpha × _u_MultiplyAlpha 按 _u_CurBlendMode 选择最终输出形式（加色/半透明混合）

3. E3 · 单图粒子（VS 2144 / PS 2145）

纹理仅 1 张 _u_MainTex 256²
VS $Globals（8 项）_u_MainRollUV 单路滚动 + _u_MainTex_ST + _u_ZOffset + 矩阵
PS $Globals（5 项）_u_Color、_u_CurBlendMode、_u_MainAlpha、_u_AlphaVal、_u_MultiplyAlpha
color = tex(uv·ST + t·RollUV) × _u_Color alpha = tex.a × _u_MainAlpha × _u_AlphaVal × _u_MultiplyAlpha // 最简粒子，性能最好；调复杂度不够时才升级到 E2/E4

4. E4 · 溶解+Rim 幽灵特效（VS 64334 / PS 64335）

4.1 资源与常量

纹理slot0 主图 128²；slot1 溶解图 256²
VS $Globals（13 项）Main/Diss 双坐标系选择（_u_MainCoordsys/_u_DissCoordsys：UV/世界/视图）+ 双 RollUV/ST + _u_Dissolve_UVChannel + _u_ZOffset + 全套矩阵（含 W2O，支持世界空间溶解）
PS $Globals（30 项）见下表
分组常量含义
基础_u_Color / _u_MainAlpha / _u_MultiplyAlpha / _u_UseAlpha / _u_AsGray / _u_CurBlendMode / _u_Main_ClampUV染色、alpha 链、去色开关、UV clamp

溶解边缘色_u_DissColor1 / _u_DissColor2双色边缘（典型：内缘亮橙+外缘暗红燃烧边）
Rim_u_RimColor / _u_RimGhost / _u_RimOffset / _u_RimSmooth / _u_ReverseGhost边缘发光；ReverseGhost=反向幽灵（边缘镂空反向渐变）
其他_u_Time / _u_WorldSpaceCameraPos / _uhlslcc_mtx4x4unity_MatrixVPS 内时间动画与视角相关计算

4.2 推测逻辑

main = tex_main(uv) × _u_Color（AsGray=1 时先转灰度） diss = 溶解图采样(_u_DissolveChannel) → smoothstep(_u_DissInt±_u_DissFea/_u_DissSmooth) edge = 1 - smoothstep(diss - _u_Dissolve_Edge, diss, ...) // 边缘带 edgeColor = lerp(_u_DissColor1, _u_DissColor2, 边缘带内位置) rim = smoothstep(NdotV + _u_RimOffset, _u_RimSmooth) × _u_RimGhost × _u_RimColor （_u_ReverseGhost=1 时取反，形成"边缘镂空"幽灵感） out = (main + edgeColor×edge + rim) × alpha链 × dissolve 裁剪
