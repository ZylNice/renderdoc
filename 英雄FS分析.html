③ 法线贴图 + TBN（含双面手性）

⑤ 光照噪声（假云影/地面光斑，_65 4×4 平铺）

⑥ GGX 直接光（L=_m12）

⑦ SH9 环境漫反射

R = reflect(−V, Nw); R.xz 绕 Y 旋转 _m4·0.0174533（度→弧度） φ = atan2(R.z, R.x) 多项式近似（0.0208351/−0.085133/0.180141/−0.330299/0.999866） θ = acos(R.y) 多项式近似（−0.0187293/0.074261/−0.212114/1.5707288） uv = (φ/π·0.5+0.5, 1−θ/π) row = roughness·5；A=_145[floor(row)]、B=_146[ceil(row)] 条带偏移表（6 条带，x∈{0.5,0.25} 两段宽） specRamp = lerp(texture(_64, uv·A.xy+A.zw), texture(_64, uv·B.xy+B.zw), fract(row)) specRamp = (specRamp.rgb · specRamp.a·6)² · _m17.rgb · (albedo.z·环境亮度)

5. RenderDoc 雾效调试指南

本材质的雾是前向分段的：距离雾因子在 VS 算好（存 _70.w，带 0.1 缩放），PS 只做 lerp；高度雾完全在 PS（_70.y 逐像素）。调试时先分清改哪一段。

5.1 不改 shader：先观测实际值

1) Event Browser 选 EID 1674 → Texture Viewer 右键英雄像素 → Debug Pixel 2) 单步到 ⑩/⑬ 段，直接看 _70.w（距离雾因子）、_m19、_m2/_m3/_m11 的运行时值 3) Pipeline State → PS → Uniform Buffers → set0/binding1 可整表查看 35 个常量当前值 4) VS 侧雾参数在 VS 的 UBO（316B：世界矩阵 + 雾 child8/9/10/11），距离雾范围要改这里

5.2 改 shader：Shader Viewer → Edit（GLSL 反编译可直接改并重编译）

目的修改（在 _152() 末尾 _72 赋值前后操作）
可视化距离雾因子分布_72 = vec4(vec3(_70.w), 1.0);（嫌暗就 ×10，因 VS 乘了 0.1）
可视化高度雾因子_72 = vec4(vec3(clamp((_70.y - _148._m3) * _148._m2, 0.0, 1.0)), 1.0);
关闭距离雾把 _84 = (_70.www * _86.xyz) + _93; 改为 _84 = _93;
关闭高度雾把 _103 = (_103.xxx * _123) + _100; 改为 _103 = _93;
雾色标红看范围把 _148._m19.xyz 替换为 vec3(10.0, 0.0, 0.0)（超亮红，雾区一目了然）
排除输出抖动干扰把 SpecConstant specID0 置 0（Edit 面板可改），或删掉 main() 里的抖动块
调距离雾远近/浓度PS 改不了——因子来自 VS。改 VS（1587006）里雾参数 UBO 的 child8/9/10，或在 VS 末尾把 _68.w（雾因子输出）乘个系数再写出
注意：距离雾 lerp 之后还有 Tonemap 与高度雾，直接把 _72 覆写成雾因子时要跳过后续计算（放在函数末尾、原有 _72 赋值之后），否则看到的不是纯因子。改完 Apply 后 RenderDoc 会重放整帧，所有用该 shader 的英雄都会生效。
