修正后的一句话结论：实时阴影分两层。 静态场景阴影走 CSM（1024×1024 D16，URP ShadowCasterPass 渲染 6 个遮挡体，地面材质硬件 Dref + 3×3 tent PCF + 距离衰减采样）。 英雄向地面的投射不走 shadowmap，而是 E2328 所在的"特效贴片族"贴地 Decal：一张 741 索引的贴地网格， 顶点着色器用 _u_ZOffset 把面片朝相机拉近消 Z-fighting，像素着色器采样 128×128 软渐变主纹理（305967）+ 256×256 遮罩（305951）， 以 _u_CurBlendMode 控制的混合模式 + 顶点色 alpha 画在角色脚下。
初版勘误：初版依据 E481/E500（_ug_ShadowExpandScale/_ug_HeroShadowIntensity、position-only 网格）推断"proxy 写入 CSM 成像"， 该写入目标始终未取得直接证据（工具缺陷），属过度推断；E2328 才是可见的角色地面投射实现（用户在 RenderDoc 中直接指认）。E481/E500 的角色定位见 ⑥。

③ CSM 阴影贴图渲染（静态遮挡体 · URP ShadowCasterPass）

六个 caster（E349/E367/E383/E409/E432/E458，90/288/2616/2868/150/6405 索引）的 VS 是逐行级别的 URP ShadowCasterPass.hlsl（glslang→SPIR-V）：

  • 法线偏移：视空间法线按 _ug_DepthBias（x=斜率、y=单位、z=Z 偏移）slope-scaled 偏移
  • Pancaking：_ug_ShadowPancaking 开启时近平面前顶点 z 钳到 1
  • 正交分支：_ug_OrthoCamera + _ug_dxCamera/_ug_dyCamera 修正视向量边缘因子
  • PS 为空壳（输出白色常量），有效输出是深度（D16）

地面材质（E1408/E1433）的阴影输入只有 296207 这张 D16——即 CSM 只承载静态遮挡体。

④ 英雄向地面的投射：E2328 贴地 Decal（核心）

E2328（glDrawElements，741 索引）位于主场景 pass 的透明段（E2228~E2343 一带），材质为通用"特效贴片"族的富变体（VS 74064 / PS 74065）。

4.1 顶点着色器（74064）：贴地 + 深度偏移

// 核心三步（完整反汇编见取证）：
// ① 计算物体缩放归一因子（WorldToObject 列向量点积自身 → sqrt → 1/len，兼容非均匀缩放）
// ② 深度偏移量：zoff = _u_ZOffset × (−2) × _u_ProjectionParams.y × normFactor
clip = unity_MatrixVP × (unity_ObjectToWorld × POSITION0);
// ③ 把面片朝相机拉近（消与地面的 Z-fighting）：
gl_Position.z = clip.z + zoff / clip.w;
// 另有 4 组滚动 UV（MainRollUV/MaskRollUV/DissRollUV/DistRollUV × _u_Time，fract）

4.2 像素着色器（74065）：软渐变 × 遮罩 × 溶解边缘 × 混合模式

dist   = DistTex.uv × 2 − 1;                         // 可选 UV 扭曲
mask   = channel(MaskTex, _u_MaskChannel);            // 256×256 遮罩，通道可选
main   = MainTex(uv + dist×Distortion_MainTex_Strength);  // 128×128 软渐变（影子的"形"）
diss   = smoothstep(edge) 溶解边缘（×x²(−2x+3) 曲线, _u_DissFea 控边宽）   // 出场/消散动画
alpha  = main.a × vertexColor.a × _u_MainAlpha × mask × diss, clamp(0,1)
color  = (_u_CurBlendMode == 4) ? main.rgb × _u_Color(遮罩混色 lerp)   // 预乘式混合
                                : main.rgb × _u_Color
out = float4(color, alpha × _u_MultiplyAlpha)
  • 影子的形状与浓淡完全由资产驱动：MainTex（305967，128×128 软渐变圆斑）给出软边，MaskTex（305951，256×256）裁形/控透明度，_u_Color 给暗色，_u_AlphaVal/_u_MainAlpha/_u_MultiplyAlpha 控浓度。
  • 动画能力：滚动 UV（流动感）、溶解边缘（出生/死亡渐显渐隐）、UV 扭曲——这是把角色投影做进特效系统而非渲染管线的好处：策划/美术可纯配置。
  • 网格：741 索引（247 三角形）——比 4 顶点 quad 细分得多，用于顶点级 alpha 渐隐（如边缘羽化、跟随棋格形状）；另有 24 索引小号实例（E2329）。

⑤ 地面接收端（CSM 采样，仅静态层）

// 地面材质 PS (76631 @ E1408/E1433) 阴影部分：
shadowPos = positionWS + normalWS × (2 − NdotL) × CSMNormalBias.x × 2;   // 法线偏移消自阴影
clip = mul(g_CSMShadowMatrices, shadowPos);
fade = clamp(lightZ × _ug_CSMDistanceFade.x + _ug_CSMDistanceFade.y);   // 距离淡出
if (fade < 1 && |clip.xy/w| < 0.9922) {
    uv = clip.xy × _ug_CSMUvScaleOffset.xy + zw;
    // 4 × ImageSampleDrefExplicitLod（sampler2DShadow 硬件 2×2 PCF）× 双线性 tent 权重 ≈ 3×3
}

⑥ E481/E500 投影网格的重新定位与其余相关项

  • E481（108 索引）/ E500（2646 索引）：VS 仅读 POSITION0、按 _ug_ShadowExpandScale 缩放后经 ObjectToWorld→MatrixVP；PS 输出单通道常量（_ug_HeroShadowIntensity，E481 变体为 1 + _u_ProjectorShadowStrength×(强度−1)）。写入目标未取得直接证据（get_draw_call_details 对该段事件失效）。在"E2328 已确认为角色地面投射"的前提下，二者更可能是：CSM 的角色 proxy 补充（方向性投影），或写入某离屏遮罩的辅助绘制——本帧 2 个实例恰与 2 个富变体贴片（741 索引 ×2：E2228/E2328）数量对应，亦可能分别服务不同单位。保留为待验证项，不再作为角色地面投射的实现依据。
  • 英雄本体不接收阴影：英雄材质（75310/75311）无任何 shadowmap 绑定，仅 _ug_HeroLightDirection 固定方向光 + rim/fresnel。
  • 帧末 "Depth-only Pass #1"（E8588）与阴影无关：静态场景深度重建（粒子软淡出/模糊反射用）。
  • GPU 计时计数器对本段无数据，未量化耗时。

⑦ 可借鉴的工程要点

  • 角色投影做进特效/Decal 系统而非 shadowmap 管线：贴地面片 + ZOffset + 软渐变纹理，成本恒定（一张 741 索引网格 + 2 次小纹理采样），不受光源角度/场景遮挡影响，且直接获得特效系的动画能力（溶解出场、滚动、扭曲、遮罩裁形）——对"单位站在棋格上"的自走棋/棋盘类游戏是性价比极高的方案。
  • ZOffset 贴地技巧：clip.z += _u_ZOffset×(−2)×ProjectionParams.y/w（含非均匀缩放归一），一个参数解决 decal 与地面的 Z-fighting，无需模板缓冲。
  • 细分贴片网格（741 索引）+ 顶点色 alpha：比 4 顶点 quad 多出顶点级羽化/异形裁剪能力，仍远便宜于角色 mesh。
  • 双层分工：静态物走 CSM（正确互遮挡、软 PCF），角色走贴地 decal（稳定、可控、可动画）——避免把高频移动的蒙皮角色塞进每帧 shadowmap caster 列表的顶点/动画开销。
  • 英雄不接收阴影：省角色材质里的 shadowmap 采样与偏移计算，用固定方向光 + rim 补偿体积感。

⑧ 数据来源、取证方法与未决项

  • 用户在 RenderDoc 中直接指认 E2328 为角色阴影地面投射（本报告修订的直接依据）。
  • E2328/E2329/E2228 材质与绑定：get_pipeline_state；算法：get_shader_source（VS 74064 / PS 74065 / 简化变体 16760/16761 全文；caster VS 73507、地面 PS 76631、英雄 PS 75311 等 30+ 事件）。
  • 同族实例分布：find_draws_by_shader（注意：该工具返回的 EID 与事件树存在偏移，已按逐事件 pipeline_state 交叉校准）。
  • 工具缺陷记录：get_draw_call_details 对 E284~E500 及帧末段事件持续返回 "No action"（导致 E481/E500 写入目标无法直接取证）；find_draws_by_resource 在 GL 截帧下全量匹配；常量缓冲数值不可读（GetConstantBuffer 缺失）。
  • 未决项：① E481/E500 的实际写入目标与用途（CSM proxy / 离屏遮罩 / 其它）；② 富变体 9 处贴片中哪些是角色阴影、哪些是其它地面特效（贴片族通用）；③ 阴影/贴片段无 GPU 计时数据。
