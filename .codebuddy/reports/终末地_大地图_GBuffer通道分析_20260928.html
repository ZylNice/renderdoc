1. 结论：是 MRT4，且按 Subpass 动态收窄

是。GBuffer 阶段（大 RenderPass 的 Subpass 1/2）同时绑定 4 个颜色附件 + 1 个 D24S8 深度；随后按阶段收窄：Subpass 3（延迟光照）只写 1 个 RT，Subpass 4（水/特殊材质）写 2 个 RT。附件格式经 SPIR-V 反汇编与管线状态双重确认，通道语义全部来自着色器输出编码的逐条解读（见第 4 节），非猜测。
Subpass事件写入目标证据
SP0 植被深度E2621–E3126126274 D24S8E2629 outputs=[]
SP1 主场景E3127–E4562绑 4+1，PS 全零仅写 L0=0（实质为 Early-Z 深度 pass）E3133/E3138/E3180/E3195/E3204 五个 draw、三个不同 PS id 均为 *Location(0) = {0,0,0,0}
SP2 GBuffer 填充E4563–E4599L0 126758L1 126262L2 126279L3 126282 + DepthE4567（全屏 resolve）与 E4573（植被）outputs 均为 4 RT

架构修正（相对系列前两篇）：SP1 的 ~330 个 draw 的像素着色器全部是"null PS"（只写 Location 0 全零）——SP1 实质是纯深度 pass（利用已绑定的 4RT FBO 与 EarlyFragmentTests）。真正的 GBuffer 材质填充发生在 SP2 的首个全屏 draw（E4567）：它读取 subpass 深度 input attachment 反投影重建世界坐标，经虚拟纹理（VT）clipmap 页表解码采样材质，一次性写满 4 个 MRT；后续 7 个植被/小物件 draw 增量覆盖。这是延迟材质化（Deferred Material Resolve）架构：几何 pass 只产深度，材质与着色数据全屏重建。

3. 通道语义取证（SPIR-V 输出编码逐条解读）

3.1 SP2 材质 resolve 着色器（E4567，PS 159061）的四个输出

Output Location 0  *_5 = _1451   // float4(颜色, 0.5)  —— A 通道硬编码 0.5
Output Location 1  *_8 = _320    // (sqrt 编码反射向量.xy, 未定义, 0)
Output Location 2  *_6 = _1464   // (octNormal.xy*0.5+0.5, roughness, 材质标志/255)
Output Location 3  *_7 = _1469   // (最终材质色.xyz, (specular*127|128)/255)

// —— Location 1 编码细节（反射向量）——
_1440 = reflectOffset（反射方向 - 视线方向, y 取反）
_1447 = sqrt(abs(_1440)) * sign(_1440)        // 平方根符号编码（压缩半球分布）
*_8  = float4(_1447 * 0.5 + 0.5, Undef, 0)

// —— Location 2 编码细节（八面体法线 + 材质位打包）——
_289 = abs(N); _290 = |Nx|+|Ny|+|Nz|
_293 = N.xz / _290                             // 八面体投影
if (N.y <= 0) { 折叠到下半球（octahedral wrap） }
_1457 = octN.xy * 0.5 + 0.5                    // 映射到 [0,1]
_1463 = ((湿度*15) << 4 + 材质ID) * 0.0039      // A 通道：8bit = 4bit 湿度 + 4bit ID

// —— Location 3 编码细节（SRGB 基色 + specular 打包）——
_306 = specular * 127; _307 = uint(_306) | 128 // 最高位=有效标志
_1468 = _307 * 0.0039                          // A 通道 7bit 精度镜面强度

同族变体 E4573（植被 draw，PS 159074）输出结构完全一致：L0=(色,0.5)、L1=(sqrt 编码,·,0)、L2=(oct 法线, 粗糙度, smoothstep 深度因子变体)、L3=(色, 深度因子变体)——证明这是引擎统一的 GBuffer 打包规范，非单着色器偶然。

3.2 SP3 光照着色器的消费方式（闭环验证）

E4604（SP3 光照全屏 draw，outputs = 仅 RT0 126758）读取：
  res20 = 126279 (RT2, RGBA8_UNORM)  → 解码八面体法线 + 粗糙度 + 材质标志
  res18 = 126282 (RT3, RGBA8_SRGB)  → 取基色 + specular
  res19 = 126274 (深度)             → 重建线性深度
  + CSM×2 (2048² D16) + 点光阴影 (512² D32) + 3D LUT (32³ R8) + cookie (1024²)
光照结果写入 RT0（唯一输出）
格式选择的工程含义：RT2 用 UNORM（法线/粗糙度是线性数据，SRGB 会破坏插值）；RT3 用 SRGB（基色是感知空间数据，硬件免费做 gamma）；RT0/RT1 承担 HDR 输出但仍是 4B/px 的 LDR 类格式（推断 RGBA8）——HDR 范围依赖后续 Karis 亮部提取（Bloom 链）的软阈值处理，这是移动端省带宽的典型取舍（对照桌面端常用的 RGBA16F GBuffer）。

4. 数据流总图

SP0/SP1（纯深度）：119+330 Draw → 126274 深度（PS 为 null，Early-Z 专用管线）

SP2（GBuffer 填充，E4567 全屏 resolve + 7 植被 draw）：
  读：深度 input attachment（subpassLoad）→ 反投影世界坐标 → VT clipmap 页表（位域解包 64×uint4） → 2DArray 材质贴图（grad 采样）→ 64 灯 cluster 位域（1024×uint4）+ 灯数据 7168B
  写：RT0 (色,0.5) RT1 (反射向量) RT2 (oct 法线+粗糙度+材质位) RT3 (SRGB 基色+specular) ＋ VT 页请求反馈 SSBO（可见性回写 CPU）

SP3（延迟光照，9 全屏）：读 RT2+RT3+深度+阴影+LUT → 写 RT0（HDR 光照输出）

SP4（水/特殊材质，38 Draw）：写 RT0 + RT1

RenderPass 结束（E4803，C=Store DS=Store） → 透明层 → Bloom（读 RT0 派生）→ 合成

5. 附加发现

  • 虚拟纹理（Virtual Texture）实锤：E4567 PS 中存在完整的 clipmap 页表解码——从 uniforms24._child0[64]×uint4（17456B 常量块）按位提取页 ID/偏移（>>20 & 1023、& 31 等位段），并以 Grad() 显式梯度采样 2DArray 物理页；同时向 SSBO（DescriptorSet 3 Binding 26）写入打包的页请求（(页ID<<24) | (tileY<<16) | (tileX<<8) 格式）——这是 VT 可见性反馈回传，引擎在移动端跑标准 VT 流水线。
  • Cluster 灯光：1024×uint4 位域标记 64 簇×灯光列表，配合 7168B 灯数据块（64 灯 × 颜色/位置/衰减/阴影参数）在 PS 内按位解包——移动端 forward+ 式 cluster lighting 在延迟材质阶段即完成光列表查询。
  • 湿度系统：RT2.A 的高 4bit 是湿度等级（wetness），着色器中有 湿度→粗糙度衰减、湿度→镜面增强、smoothstep 高度衰减 三条联动分支——大地图雨后湿地/水坑表现的数据基础。
  • 材质 ID：RT2.A 低 4bit 材质 ID，着色器内出现 id*255 == 19/== 15 的特判（鞋印/水花类 SFX 分支）。

6. 数据来源

  • 输出目标：get_draw_call_details @ E2629（SP0 仅深度）/ E3204·E4567·E4573（4 MRT）/ E4604（仅 RT0）/ E4643（RT0+RT1）
  • SP1 null PS：get_shader_info(pixel) @ E3133/E3138/E3180/E3195/E3204 —— PS 132516/132519/132521 三 id 均为 Location(0)={0,0,0,0}
  • GBuffer 编码：get_shader_info(pixel) @ E4567（PS 159061，1470 id 完整反汇编）与 E4573（PS 159074，1201 id）
  • SP3 消费与格式：get_pipeline_state @ E4604（res18=126282 SRGB / res20=126279 UNORM / 深度 126274）；E4567/E4573 管线状态确认 126279=RGBA8_UNORM、126282=RGBA8_SRGB
  • subpass 边界：E2621 Begin / E3127·E4563·E4600·E4637 NextSubpass⇒1–4 / E4803 End（详见系列前篇《Subpass 深度分析》）

注：RT0(126758)/RT1(126262) 的像素格式未在本帧绑定中直接暴露（无后续采样点），按 4B/px 与用途推断为 RGBA8 类；其余结论均有 SPIR-V/管线状态直接证据。
